# 모눈별 수학학원

가상 업체 포트폴리오 샘플입니다. 실제 업체의 영업·상담·모집·서비스가 아닙니다.

수학학원 소개와 학원 소식 관리를 위한 홈페이지입니다. 차분한 보라와 밝은 종이색으로 구성합니다.

## 쪽 목록

- `index.html` — 첫 화면
- `about.html` — 학원 소개·사진
- `courses.html` — 강좌
- `notices.html` — 공지·검색
- `blog.html` — 배움 노트
- `contact.html` — 문의 미리보기
- `admin/index.html` — 관리 체험

## 기능 체험

관리 체험 → 편집 화면 열기 → 공지·글·사진 선택 → 추가·수정·삭제 → 공개 화면과 새로고침으로 반영 확인. 샘플 이미지 또는 300KB 이하 PNG/JPG/WebP를 사용할 수 있습니다. 실제 개인정보가 포함된 파일은 사용하지 마세요. 내용은 현재 브라우저 localStorage에만 보관되며 처음 상태로 되돌리기를 제공합니다. 관리 체험은 보안 인증이 아닙니다.

## 사용 기술

HTML5 · CSS3 · Vanilla JavaScript. 글꼴은 Google Fonts의 Noto Sans KR을 요청하며 글꼴 파일은 저장소에 포함하지 않습니다. 글꼴을 가져올 수 없으면 시스템 sans-serif를 사용합니다. 키보드 포커스·모바일 메뉴·움직임 줄이기 설정을 지원합니다. 분석 스크립트·외부 폼·결제 연동이 없습니다.

이미지: `images/` 폴더의 사진.
